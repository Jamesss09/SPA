# SPA — Agent Rules

## Session summary (required)

After every work session where files were read/changed, commands were run,
or tests/builds executed, end your final response with a summary:

1. What happened — 1-3 sentence outcome.
2. Changes — list each created/modified file with 1-line reason.
3. Verification — commands run plus pass/fail output (e.g. `php artisan test`, `npm run build`).
4. What's next — next phase/task or `None — awaiting input`.

Rules:
- Base the summary only on executed tool results, not assumptions.
- If nothing changed, say so explicitly.
- Keep it short and factual, no superlatives.
